## 📦 data-API

A simple JSON data API built to serve structured data like books, news, developer notes, and roadmap information. This project provides static JSON endpoints that can be used for demos, learning purposes, or as a mock backend for frontend applications.

 ⚡️ A minimal data API using static JSON files — ideal for prototyping and learning how to fetch and work with API data in front-end applications.
```
data-API/
├── public/
│   └── API/
│       ├── books.json
│       ├── developer.json
│       ├── news.json
│       ├── notes.json
│       └── roadmap.json
├── README.md
└── (other files)
```
